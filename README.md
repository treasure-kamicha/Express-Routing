## DESCRIPTION

This skincare project is a modern, web-based platform designed for Glow Care, a holistic skincare brand focused on healthy, radiant, and nourished skin.

## TECH STACKS

Node.js
HTML
Express.js
CSS

## USAGE

Open your terminal in the project directory and start the server:node app.js
Open your web browser and go to http://localhost:3000.
